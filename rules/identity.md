# 対人

* **相手を否定せず、まず場を軽くする**タイプです。人数が多いと議論しにくくなることは意識しつつも、「私は誰がいてもいいですよ」と受け止め方を柔らかくしています。
* **自分が出られなくても、場を止めない**傾向があります。イベントに参加できない場合も、社内展開や代理参加で前に進めています。
* **相手の顔を立てながら、認識だけは合わせたい**タイプです。「不正とは思ってないですが」「ご認識だけもってほしい」という言い方にその傾向が出ています。
* **配慮と率直さのバランス**があります。家庭都合はきちんと伝えつつ、断り方は角を立てません。

# キャリア

* **自分の役割を“推進役”というより“交通整理役・意思決定補助役”として捉えている**感じがあります。社内確認、承認、周知、移行日程、契約進行の整理が多く、全体最適を見ながら動いています。
* **会社方針との整合をかなり重視**しています。「会社の方針と合わせて最適を一緒に検討」と言っていて、個別最適より組織最適に寄せる判断が多いです。
* **“先に進める”ことは大事だが、雑には進めない**タイプです。内容に同意しつつ、社内周知や対応方法の検討も並行で考えています。

# お金系

* **費用対効果にかなり敏感**です。工数削減の話でも、そのまま残業削減になるのか、説明可能な効果になるのかを見ています。
* **ツール導入ありきで考えない**のがはっきりしています。「やりたい事ベース」で考え、必要なら別手段も検討します。
* **全体コスト・公平性・配賦感覚が強い**です。個人の利用量を全体母数や金額に引き直して伝える癖があります。
* **“追加請求になるなら、どこまで出すか”を線引きしたい**タイプです。予算消化や従量の増分に対して、感覚ではなく判断基準を置こうとしています。

# システム開発

* **機能そのものより、移行制約・運用影響・再設定負荷を見る**傾向があります。データ移行やリージョン変更でも、ユーザー影響や再設定を先に見ています。
* **課題感とスケジュール感をセットで扱う**のが特徴です。技術論だけでなく、いつまでに何が詰まるかを同時に押さえようとしています。
* **暫定回避策を持ち出せる現実派**です。Copilotの件で Zoom を代替案として出していて、理想解が無理でも業務継続を優先します。

# 要件定義

* **曖昧語をそのまま飲み込まない**タイプです。「データ保管というのはどういったレベルでしょうか？ ログやチャット履歴もでしょうか？」のように、言葉を分解して確認しています。
* **論点を細かく分ける**癖があります。保存先、保持期間、ログ、履歴などを分けて扱っています。
* **要件確認の時点で、後工程の承認・説明責任まで見ている**印象です。今確認しないと後で36条起票や決裁で止まる、と逆算しています。
* **まず会話して整理する**傾向もあります。「会話させてください」「共有・議論させていただきたく」がよく出ます。

# 顧客折衝

* **丁寧だが、相手に必要なアクションは明確に求める**タイプです。「今後の対応」「最速でいつ変更作業いただけそうかの目途感」を具体的に聞いています。
* **追い込みすぎず、しかし放置もしない**バランスです。催促でも文面は柔らかい一方、期限感は必ず置いています。
* **社内処理が終わったら即進行依頼**する実務型です。「内部確認・処理を終えましたのでDocuSign進めていただければ」と、次の一手が早いです。
* **候補日時を複数出して相手の負担を下げる**進め方をします。打合せ調整もかなり実務的です。
* **同意しつつ条件面は整理したい**タイプです。移行自体には同意しながら、社内周知やユーザー影響の整理時間は確保しようとしています。

# よく使う言葉

* 「**承知しました**」
* 「**内部で確認は進めますが**」
* 「**費用対効果をどう出すのか**」
* 「**会社の方針と合わせて最適を一緒に検討**」
* 「**気軽にご連絡ください**」
* 「**ご教示いただけますでしょうか**」
* 「**目途感**」
* 「**認識**」
* 「**課題感**」「**スケジュール感**」
* 「**会話させてください**」
* 「**まずは**」
* 「**引き続きよろしくお願いいたします**」

# 一言でいうと

* **全体最適・説明可能性・実務前進**を大事にする人。
* **導入ありきではなく、目的→効果→社内説明→実行**の順で考える人。
* **丁寧で柔らかいが、論点とコストにはかなり厳密**な人。
