# README Generator スキル

このスキルが呼び出された際は、以下の手順に従って `README.md` を作成または更新してください。

## 実行手順

1. **プロジェクト構成の解析**
   - リポジトリ内のディレクトリ構造や設定ファイルをスキャンします。
   - 依存関係ファイル（例: `package.json`, `requirements.txt`, `go.mod`, `Cargo.toml`, `pyproject.toml` 等）を確認し、使用技術スタックと言語・フレームワークを特定します。
   - 既存の `README.md` が存在する場合は差分と不足している情報を整理します。

2. **重要情報の抽出・整理**
   - **概要**: プロジェクトの目的と解決する課題
   - **主な機能（Features）**: 主要な機能一覧
   - **前提条件（Prerequisites）**: 必要なランタイム、ツール、バージョン
   - **セットアップ（Installation / Setup）**: クローンから依存関係インストールまでのコマンド
   - **使用方法（Usage）**: 起動方法、基本的なコマンド例、APIエンドポイントなど
   - **環境変数 / 設定（Configuration）**: `.env` や設定項目の説明（サンプル値を含む）
   - **テスト・開発（Testing / Development）**: テストの実行方法やビルド手順
   - **ライセンス（License）**: リポジトリのライセンス表記

3. **README.md の生成**
   - GitHubで読みやすく統一感のあるMarkdown形式で出力します。
   - 適切な見出し階層（`#`, `##`, `###`）、言語指定付きコードブロック、表、リストを使い、分かりやすいレイアウトにします。
