# 🚀 Staging Deployment Runbook

## 概要
ステージング環境への安全で再現性のあるデプロイを自動化・標準化するための手順書です。

## デプロイ手順（基本プロセス）
1. **環境変数の検証**:
   - `.env.staging` が正しくロードされているか確認する。
2. **ビルドの実行**:
   - パッケージのインストール (`npm install` 等)
   - ビルドの実行 (`npm run build` 等)
   - ビルドエラー、型エラー、Lintエラーがないことを確認。
3. **自動テストの実行**:
   - ユニットテストとE2EテストがPassすることを確認する。
4. **アセットの同期とサービスの再起動**:
   - ビルドされた成果物をサーバーまたはホスティングサービスにアップロードする。
5. **デプロイ後検証 (Post-Deploy Check)**:
   - 正常にアクセスできるか（ステータスコード200）、エラーレートが上昇していないかを監視する。
